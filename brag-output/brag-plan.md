# Brag Plan: Abi Kurian Varghese — Portfolio

## What is this app?
The personal engineering portfolio of Abi Kurian Varghese — showcasing full-stack PWAs with offline-to-cloud data parity, secure PostgreSQL Row Level Security, ML models, and intentional brutalist design with zero vibe-coded SaaS tropes.

## The angle
Quiet, confident engineering authority. In a sea of cookie-cutter, gradient-drenched AI developer portfolios, this site stands as a sharp, monolithic monument to real engineering: data integrity, algorithmic thinking, and structural restraint.

## Hook (first 2-3 seconds)
Extreme high-impact reveal: The colossal, screen-filling editorial type "ABI KURIAN / VARGHESE" stamps onto the dark canvas over a responsive coordinate grid, immediately followed by the lime-chartreuse role badge: "FULL-STACK DEVELOPER".

## Key moments (the middle)
1. **Interactive Technical Spec Sheet**: Rapid-fire reveal of production stacks (Supabase RLS, Dexie.js, Flutter, Ollama, Python, TypeScript) highlighted by sharp laser hairline rules.
2. **Selected Work Breakdown**: Focus on *SpendStudent* — two-way offline-to-cloud sync with Row Level Security, and *Smart Yatra* — geolocation dynamic polling optimization.
3. **No Fluff Guarantee**: "Built where data has to stay correct." Crisp code-like clarity.

## Outro / punchline
The monumental typography locks into the direct terminal contact: `abikurianvarghese@gmail.com` with a clean copy-action trigger and the live domain `abikurian.dev`.

## User flow worth showing
1. **Hero Entry**: Colossal name + kinetic coordinate grid reacting to position.
2. **Spec Sheet Exploration**: Hover/tap across Languages, Web, Data & Cloud with dynamic border-draw feedback.
3. **Architecture Drilldown**: Accordion expands SpendStudent demonstrating offline-to-cloud parity.
4. **Direct Channel**: Immediate contact link.
